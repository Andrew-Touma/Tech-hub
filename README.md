# Electro - Electronics Website Template

Electro is a modern, fully responsive e-commerce website template specifically designed for electronics stores. The project focuses on providing a seamless user experience across all devices, leveraging a robust frontend architecture.

## Key Features

###  Responsive Frontend
The core of this project is its **mobile-first, responsive design**, ensuring that the store looks and functions perfectly on desktops, tablets, and smartphones.

- **Bootstrap Integration**: Utilizes the latest Bootstrap framework for a grid-based layout that adapts dynamically to screen size.
- **Custom CSS**: Enhanced with a dedicated `style.css` to provide a unique brand identity, polished typography, and refined UI elements.
- **Fluid Layouts**: Uses flexible containers and rows to maintain visual harmony across different resolutions.

###  E-Commerce Functionality
- **Product Catalog**: A comprehensive shop page with category-based filtering (Accessories, Electronics, Laptops, Mobiles, etc.).
- **Dynamic Product Tabs**: "All Products", "New Arrivals", "Featured", and "Top Selling" tabs for easy navigation.
- **Shopping Experience**:
    - Integrated **Shopping Cart** and **Checkout** pages.
    - "Add to Cart" functionality for a streamlined purchase flow.
    - Product labels for "New" and "Sale" items.
- **Interactive Elements**:
    - **Owl Carousel**: An elegant, touch-enabled image slider for featured banners and offers.
    - **Wow.js & Animate.css**: Smooth scroll-in animations that bring the page to life as the user explores.
    - **Lightbox**: High-quality image previews for products.

### 🛠️ User-Centric Design
- **Advanced Navigation**: A multi-layered header including a top bar for support/account settings and a primary navbar with a category dropdown.
- **Search Capability**: A prominent search bar with category selection to help users find products quickly.
- **Customer Trust signals**: Dedicated sections for "Free Shipping", "Secure Payment", and "24/7 Support".
- **Contact System**: A professional contact page for customer inquiries.

## 🛠️ Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: [Bootstrap](https://getbootstrap.com/)
- **Libraries**:
    - `Owl Carousel` (Sliders)
    - `Wow.js` & `Animate.css` (Animations)
    - `Lightbox` (Image Galleries)
    - `FontAwesome` & `Bootstrap Icons` (Iconography)
    - `Google Fonts` (Open Sans & Roboto)
